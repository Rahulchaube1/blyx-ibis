# Ibis starter

Reconcile an invoice with split payments in integer minor units.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Ibis** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
300
300
0
25
```

The vendor directory contains the framework source for 0.1.1 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/ibis) · [View the release](https://github.com/Rahulchaube1/blyx-ibis/releases/tag/v0.1.1)
